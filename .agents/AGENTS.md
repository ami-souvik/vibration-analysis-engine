# Project Rules

## Git Commit Policy
- **MUST ASK BEFORE COMMIT**: Do NOT run `git commit` or `git push` automatically after completing a task or editing files.
- Only run `git commit` / `git push` if the user explicitly requests it in their message (e.g., "commit the changes", "publish the branch", etc.).
- In all other cases, present the changes/results to the user and wait for explicit confirmation before committing.
